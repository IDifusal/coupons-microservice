# Coupons Microervice

Microservice to validate coupons based on classes

## How to run?

### Environment Variables

You must set the following variables into your machine
PORT_HTTP=

DEBUG=

DB_USER=

DB_PASSWORD=

DB_HOST=

DB_NAME=

DB_PORT=

## Available commands

npm run dev -> Initialize express server with [Nodemon](https://www.npmjs.com/package/nodemon)

npm test -> Executes tests
